Reverse a number — peel a digit, paste it on the other side

N % 10 peels off the last digit. N / 10 shifts the rest right.

CODE
int reverse = 0;
while (N > 0) {
int d = N % 10;
reverse = reverse * 10 + d;
N = N / 10;
}
print(reverse);
Why "× 10 + d"? If reverse holds 13 and the new digit is 5, we want 135. Multiplying by 10 makes room (13 → 130), then adding d slots it in (130 + 5 = 135).
