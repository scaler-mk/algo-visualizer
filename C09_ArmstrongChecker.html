Armstrong primer

Definition: An Armstrong number equals the sum of its digits each raised to the power 3.

153 = 1³ + 5³ + 3³
    = 1 + 125 + 27
    = 153 ✓

Note: the strict mathematical definition uses the digit count as exponent. This class uses 3 for all numbers — sticking to the source script's spec.
