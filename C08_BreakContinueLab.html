break — exit the loop

Stops all iterations from happening. Anything after the break in the current iteration is also skipped. The loop simply ends. Quiz 3 vs Quiz 4: same break, but in Quiz 3 the print happens first, so 3 gets printed; in Quiz 4 the break fires before print, so 3 is missing from output.

continue — skip this one

Jumps back to the top of the loop. The current iteration's remaining statements are skipped, but the loop keeps going. The update step (i++) still happens. In Quiz 5, i=3 is skipped, but 4 and 5 still get printed.
