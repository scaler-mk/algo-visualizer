Data Type Buckets: will it fit?

Same water (a number), different buckets. The bigger the bucket, the bigger the value it can hold.

Try: 100 200 50000 2000000000 10000000000 9000000000000000000
Try a value above and watch how it fills each bucket. Most beginners use int for whole numbers (~±2.1 billion) and long for bigger (~±9 quintillion). byte and short are rarely used.
