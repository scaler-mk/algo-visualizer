Descending Loop — print n to 0

Print even numbers from n down to 0. Two extra moves: if n is odd, knock it down first. Then descend by 2.

Try n = 10even 17odd 8even 5odd 0edge 1edge
Source code
int n = scn.nextInt();
if (n % 2 == 1) n--; // adjust odd to even
int i = n;
while (i >= 0) {
SOPln(i);
i -= 2;
}
