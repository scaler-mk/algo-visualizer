Animation 3 · Row to Column Zero — the 3-pass marker trick

Use −1 as a temporary marker. Pass 1 marks rows containing 0, Pass 2 marks columns containing 0, Pass 3 converts every −1 to 0.
Algorithm
# Pass 1: mark rows that contain 0for i in range(N):    flag = (any zero in row i)    if flag:        for j in range(M):            if A[i][j] != 0: A[i][j] = -1# Pass 2: mark cols that contain 0for j in range(M):    flag = (any zero in col j)    if flag:        for i in range(N):            if A[i][j] != 0: A[i][j] = -1# Pass 3: convert markers to 0for i in range(N):    for j in range(M):        if A[i][j] == -1: A[i][j] = 0
