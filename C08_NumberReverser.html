Two things to notice

Trailing zeros vanish. Try n = 2400 in reverse mode — the output is 42, not 0042. The integer type can't store leading zeros. The first digit pulled is 0, but rev = 0*10 + 0 = 0 doesn't show.

Negatives flip first. The script's code flips a negative n to positive before the loop, then re-negates at the end. The digits of -417 are the same as the digits of 417; the sign rides along separately.
