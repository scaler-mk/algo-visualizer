range() — generate sequences for your loops

range(start, end, step) is half-open: stop value NEVER appears. Step direction must point from start towards end, or the sequence is empty.
START END STEP
PRESETS
range(5) → 0, 1, 2, 3, 4
REASONING start=0, end=5, step=+1. Going from 0 toward 5 by adding 1 — produces 5 values, ending just before 5.

included value end value (excluded) start position not in range
