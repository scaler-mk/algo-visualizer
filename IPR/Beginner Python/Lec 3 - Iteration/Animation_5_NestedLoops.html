Nested loops — outer drives the row, inner fills the column

For every ONE step of the outer loop, the inner loop runs to completion. That's how a 1D loop becomes 2D. Watch the cells fill in left-to-right, top-to-bottom.

1 outer × N inner = 2D — a single for loop produces 1D data (a row). Add another loop around it, and you get a 2D structure. For a 3D structure, add a third loop. Pattern continues for any number of dimensions.
