The gotcha — / vs //
TRUE DIVISION ( / )
10 / 5
2.0
Returns float — always. The .0 is Python 3's way of saying "this is a floating-point number."
vs
FLOOR DIVISION ( // )
10 // 5
2
Returns int — drops the decimal part. Useful when you need a whole-number result.
DevOps angle → this distinction matters in real scripts. Calculating "how many full backups fit on a 100GB disk if each is 7GB?" needs 100 // 7 = 14 (whole backups). Calculating "average response time" needs total_time / requests (you want the decimal).
