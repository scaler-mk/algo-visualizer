Nested if — putting an if inside another if

When the second question only makes sense if the first answer is yes, you nest. Watch the decision tree — three different paths reach three different characters.

Why nest? The question "is your character good?" only makes sense if we already know it's male. With a flat if-elif chain, we couldn't ask different follow-up questions based on the first answer. Nesting lets the SECOND question depend on the FIRST answer.
