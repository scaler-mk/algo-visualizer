Animation 2 · Two-pointer Reverse

Two pointers — i starts at 0, j starts at N−1. Swap. Move toward each other. Stop when i ≥ j.
Choose N:
Pseudocode
function reverse(arr[], N) {    int i = 0;    int j = N - 1;    while (i < j) {        temp  = arr[i];        arr[i] = arr[j];        arr[j] = temp;        i++;        j--;    }}
