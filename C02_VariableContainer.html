Variables: containers with a type, name, and value

A variable is just a labeled box. Step through and watch what each line of code does to the box.

Main.java
int num = 34;
System.out.println(num); // uses the value
num = 99; // reassign
System.out.println(num);
int b; // declare, no value yet
b = 40; // assign later
System.out.println(num + b);
