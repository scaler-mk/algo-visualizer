⚡ Why >= and not >?

If we wrote a > b && a > c instead of >=, then for input a=3, b=3, c=3 the chain would print "c" — because every comparison would be false. Ties need >= so that "tied for first" still counts as winning. We pick one of the tied values arbitrarily, and that's fine — they're equal anyway.
