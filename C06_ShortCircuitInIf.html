&& short-circuits when LEFT is false

In X && Y, if X is false, the answer must be false. Java doesn't bother evaluating Y. If Y contains ++b, that bump never happens.

|| short-circuits when LEFT is true

In X || Y, if X is true, the answer must be true. Java skips Y. Any side-effect in Y — including ++b — is silently skipped.
