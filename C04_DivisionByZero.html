The two rules

Integer division by 0
Always a runtime crash — ArithmeticException: / by zero. Java's int type has no "infinity" concept. 0/0 crashes the same way.
Floating-point division by 0
Never crashes. Non-zero ÷ 0 = Infinity (or -Infinity). 0.0 / 0 = NaN (Not a Number). This is the IEEE 754 standard for floats and doubles.
