print vs println

Same output text. Different cursor behaviour. Watch what happens after each statement runs.

📌 print()
System.out.print("Hello Guys!!");
System.out.print("Welcome to Scaler!");
↩ println()
System.out.println("Hello Guys!!");
System.out.println("Welcome to Scaler!");
print()
Just types the output. Cursor stays put — next print continues on the same line.
println()
Types the output and presses Enter. Cursor moves to the next line.
