Animation 3 · Sliding window — max subarray sum of length K

N = 10, K = 5. First window: full sum. Each next window: drop A[i−1], add A[j]. Track max as we go.
Pseudocode
function maxSubarrayK(A, N, K) {    ans = -infinity    i = 0;  j = K-1    sum = 0    for (idx -> i to j) {        sum += A[idx]   // initial window    }    ans = max(sum, ans)    j++; i++    while (j < N) {        sum = sum + A[j] - A[i-1]        ans = max(sum, ans)        i++; j++    }    print(ans)}
