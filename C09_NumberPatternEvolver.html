The three patterns differ in ONE line

Pattern 1 · val OUTSIDE outer

int val = 1; placed BEFORE the outer loop. val persists across rows — keeps growing from where the last row left off.

Pattern 2 · val INSIDE outer

int val = 1; placed INSIDE the outer loop, before the inner. val resets to 1 at the start of every row.

Pattern 3 · val = i

int val = i; inside outer. val resets to the current row number each iteration — so row i starts at i.
