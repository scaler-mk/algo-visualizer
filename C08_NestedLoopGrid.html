The trick: different patterns just change the inner loop's bound. Square: j <= N. Staircase: j <= i (depends on outer). Reverse: j <= N − i + 1. Diamond half: j <= N − i + 1 stars, then j <= 2(i − 1) spaces, then more stars. Same structure, different formulas.
