Range Checker

"Normal temp is 98.0 to 98.9" — sounds simple, but a beginner-favourite mistake is writing it as 98.0 <= temp <= 98.9. That doesn't work in Java. Here's why, and what to write instead.

✗ Wrong — chained comparison

if (98.0 <= temp <= 98.9) {
  "Normal temperature"
}
Java won't compile. The left side 98.0 <= temp returns a boolean, then Java tries boolean <= 98.9 — illegal.

✓ Correct — two conditions with &&

if (temp >= 98.0 && temp <= 98.9) {
  "Normal temperature"
}
Two separate boolean checks, joined with && (AND). Both must be true for the body to run.

The takeaway

Math notation doesn't map to code. The math expression 98.0 ≤ temp ≤ 98.9 is just shorthand for two conditions joined by AND: (98.0 ≤ temp) ∧ (temp ≤ 98.9). Java forces you to write that out explicitly.

Whenever you need a range check, write it as two separate conditions joined by &&. Same pattern for "between X and Y," "valid age 18 to 60," "score in passing range," etc.
