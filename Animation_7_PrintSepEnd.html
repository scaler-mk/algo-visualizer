print() — sep and end, hands-on

sep is the glue between items inside one print(). end is what comes after the print finishes. Change either — see the output update live.
ITEMS TO PRINT
sep (between items)
end (after print)
YOUR PRINT() CALL
CONSOLE OUTPUT
Default values: sep=" " (space), end="\n" (newline). Change either to see how the output transforms.

CHAINED print() CALLS — SEE end IN ACTION
CODE
print(1, 2, 3, end=" ")
print(4)
OUTPUT
1 2 3 4
The big idea → with the default end="\n", every print() finishes by starting a new line. Change end to " " (space) and the NEXT print() continues on the same line. This is how you build output across multiple print() calls.
