a++ (post-increment)
Use the value first, then bump.
System.out.print(a++) is equivalent to:
System.out.print(a); a = a + 1;
Print sees the OLD value.
++a (pre-increment)
Bump first, then use the new value.
System.out.print(++a) is equivalent to:
a = a + 1; System.out.print(a);
Print sees the NEW value.
