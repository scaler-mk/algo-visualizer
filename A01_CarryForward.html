Animation 1 · Carry forward — sum of all subarrays in O(N²)

For each start i, reset currSum to 0. Walk j forward. Each step: currSum += arr[j], total += currSum. No prefix array.
Pseudocode
function totalSubarraySum(arr, n) {    total = 0    for (i -> 0 to n-1) {        currSum = 0        for (j -> i to n-1) {            currSum += arr[j]            total += currSum        }    }    print(total)}
