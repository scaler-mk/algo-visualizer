Count occurrences — single sweep with a counter

Walk the array once. For each element, check if it equals the target. If yes, bump the counter. Simplest pattern of all — but the foundation for everything that follows.

Pattern recognition → this exact pattern — sweep + counter — is the bone structure of dozens of interview problems. Count vowels, count uppercase, count evens, count divisibles. The condition changes, the structure doesn't.
