The prompt this came from

"I'm writing Java code to classify a number as positive even, positive odd, negative even, or negative odd. Help me list all the edge cases I should handle. For each, tell me (1) what input triggers it, (2) what should happen, (3) how my naïve code might fail."
AI returns (abridged):
  • Zero (n == 0): Trigger: n = 0. Should: print "Zero" or similar. Failure: 0 % 2 == 0 is true and 0 > 0 is false, so naïve code falls into the negative branch and prints "Negative and even" — wrong.
  • INT_MIN (n == -2147483648): Trigger: extreme negative. Still classifiable, but Math.abs(n) would overflow if used. The mod-based code happens to work here.
  • Non-integer input: Trigger: user types "abc". Should: handle gracefully. Failure: scn.nextInt() throws an InputMismatchException.
