ArrayList — five basic operations, live

The five-method interface: add, get, size, remove, set. Each one mutates or reads the list. Watch how the contents and size pill update in real time.

arr.add(2);

arr.add(5);
System.out.println(arr);
System.out.println("2nd element is: " + arr.get(2));
System.out.println("Size is: " + arr.size());
arr.remove(1);
System.out.println(arr);
arr.set(1, 8);
