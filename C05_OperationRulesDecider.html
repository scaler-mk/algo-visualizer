RULE 1 — Decimal vs Non-decimal
Mix a decimal type (float or double) with a non-decimal (int or long)? The result is decimal.
RULE 2 — Same Category, Bigger Wins
Both operands non-decimal? Result is the bigger one (int < long). Both decimal? Same idea (float < double).
