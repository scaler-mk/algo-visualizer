Animation 2 · Contribution technique — sum of all subarrays in O(N)

For each element arr[i]: count its (i+1) left choices × (n−i) right choices. Add arr[i] × that count to total.
Pseudocode
function sumOfAllSubarraySums(arr) {    n = arr.length    total = 0    for (i -> 0 to n-1) {        contrib = arr[i] * (i+1) * (n-i)        total += contrib    }    return total}
